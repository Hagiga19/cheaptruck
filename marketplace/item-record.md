# Marketplace Item Record

## Status

Initial record expanded for candidate pools and listing health. Data availability must be confirmed through research.

## Fields

- Listing identifier and URL
- Candidate pool identifier, item role, and ranking label
- Title, description, category, and photos
- Seller-stated condition
- Listed price and currency
- Negotiated price when available
- Location and distance
- Width, depth, height, and measurement source
- Listing health, availability status, last checked time, and evidence source
- Missing critical information and confidence notes
- Seller response history
- Search and request versions that produced the item
- Fit result supplied by Measurements
- Design options using the item
- Replacement relationship to a prior listing, when relevant

Never replace the listed price with a negotiated price; preserve both.

Never replace a stale or unavailable record with a new listing; link the replacement and keep both records for history.
