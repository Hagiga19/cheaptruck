# Marketplace Context

## Purpose

Use this folder for finding, evaluating, tracking, and communicating about Facebook Marketplace items.

Marketplace acts as CheapTruck's procurement brain: it maintains living candidate pools and listing health so room designs remain buyable as secondhand inventory changes.

## Owns

- Search queries, filters, and result collection
- Candidate pools, ranking labels, and replacement shortlists
- Listing normalization and comparison
- Listing health, current price, and availability status
- Seller communication and negotiation records
- Replacement searches when listings change
- Marketplace-specific constraints and research

## Does Not Own

- Whether an item physically fits
- How items are combined into a room design
- User-facing screen layout

## Files

- `search-rules.md` - how suitable listings are found and ranked
- `candidate-pools.md` - living shortlists, listing health, and replacement behavior
- `item-record.md` - normalized information stored for each listing
- `seller-messaging.md` - approval, availability, and negotiation flow
- `research-notes.md` - verified Marketplace behavior and constraints

## Status

V1 product direction: Marketplace maintains candidate pools, listing health, and replacement searches. Actual Marketplace access and communication capabilities must be verified before implementation.
