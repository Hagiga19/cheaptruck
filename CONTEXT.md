# Current Project

CheapTruck is a planned website for affordable home design using AI, user-uploaded room photos, measurements, style goals, budget limits, and Facebook Marketplace item options.

## Current Stage

Stage: project structure and planning documents.

## What Good Looks Like

- Product rules are split by clear ownership: UI, Requests, Measurements, Marketplace, Room Designs, and Workflow.
- Technical architecture, database, storage, containers, deployment, and build notes route through `tech/`.
- Future work starts from the owning folder's `CONTEXT.md`.
- User intent, measurements, Marketplace candidate pools, listing facts, design decisions, and workflow states remain distinguishable.
- Planning files stay short enough to load only the context needed for one task.

## Not In Scope Yet

- Full implementation
- Final branding
- Live Facebook Marketplace integration
