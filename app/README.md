# CheapTruck App

First runnable UI prototype for CheapTruck.

## Run

```powershell
npm install
npm run dev
```

## Scope

- Front-end-only React/Vite prototype.
- No real authentication, storage, Facebook, Marketplace, seller messaging, or payment integration.
- Mirrors the current UI notes: account and address first, then room creation, design options, and saved rooms.
